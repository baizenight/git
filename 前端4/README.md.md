## 1.三个函数分别表示什么

- different 函数表示求a数组中与b数组中不相同的元素
- intersection 函数表示输入一个数组的数组，输出这些数组中都包含的元素
- union 函数表示输入一个数组的数组，输出这些数组中所有不重复的元素

## 3.set 和数组的区别
#### **set**

- 无序索引、值唯一的集合，靠值本身访问
- 只关心值是否在里面
- 常用来去重，判断存在，进行集合运算

#### **array**

- 有序的、可重复的值列表，靠下标访问
- 只关注第几个值是多少
- 常用来处理有关顺序，需要靠下标读取的问题

#### set 在本题中的作用

- 因为 set 不允许有重复元素存在，所以在合并集合的时候可以用来去重
