## 阶段一：把反向传播从黑盒变成白盒（约 1 周，最重要）

**目标**：能不看代码手写一个两层 MLP 的前向 + 反向。

**做法**：看 `numpy_mlp.py`（同目录），但顺序必须是——
1. 先自己推导：给定 `Z1 = XW1ᵀ+b1, A1 = ReLU(Z1), Z2 = A1W2ᵀ+b2`，手推出 `dW2 / db2 / dW1 / db1`
2. 推完再对照 `numpy_mlp.py`，标出自己错的地方
3. 然后**关掉文件**，从空文件重写一遍，跑到 acc=1.0

**两个必须记住的结论**：
- `dZ2 = sigmoid(Z2) - y`（Sigmoid + BCE 组合后的极简形式，这就是"与 Softmax 组合后梯度化为 ŷ-y"的同一件事）
- `dZ1 = (dZ2 @ W2) * (Z1 > 0)` —— ReLU 的导数就是"正区间 1、负区间 0"

**验收标准**：写完后能回答"`optimizer.step()` 具体改了哪几个数组的哪几个元素"。

**进阶（可选但强烈推荐）**：看 Andrej Karpathy 的 **micrograd**（约 150 行，从零实现自动求导）。看完你会彻底明白 `loss.backward()` 为什么能自动算出所有梯度。这是投入产出比最高的一步。再往后 **micrograd → makemore → nanoGPT** 是他同一系列，可以一直用到 Transformer。

## 阶段二：把"样板答案"变成"亲手弄坏"（约 1 周）

这是直接针对你 ml-2 里那句自省的。**不要读，要实验。** 每组实验都只改一个变量：

| 实验 | 怎么弄坏 | 你该看到什么 |
|---|---|---|
| 初始化 | 把 He 初始化改成 `*0.01` / `*10` / 全 0 | 全 0 时 loss 完全不降（对称性没打破）；过小则信号逐层衰减；过大则输出饱和、梯度爆炸 |
| 激活函数 | ReLU 换成 Sigmoid（隐藏层） | 加深到 5 层后浅层学不动 → 亲眼看到梯度消失 |
| Dead ReLU | lr 调到 5.0（过大） | 统计每层"输出恒为 0"的神经元比例，会看到大量神经元永久死亡 |
| BN | 在 ReLU 前加 `nn.BatchNorm1d` | 允许更大 lr、收敛更快；再故意用 `batch_size=2` 看它抖动 |
| Dropout | 关掉 `model.eval()`，在测试时也开 Dropout | 准确率明显下降 → 理解"训练/推理必须切模式"不是教条 |
| 权重衰减 | Adam 换 AdamW，λ 从 0 扫到 0.1 | 看训练/验证 loss 间隙怎么变 → 理解正则化在对抗什么 |

**关键要求**：每做一个实验，**画一张曲线图并写一句话结论**（像你 ml-2 的错题集那样）。
**验收标准**：能用一句话向别人解释"Dead ReLU 为什么会永久死亡，以及为什么 lr 过大是主因"——不靠背。

> 这一阶段做完，你会发现"过拟合/梯度消失/Dead ReLU"不再是名词，而是你见过的画面。这就是从"会答题"到"会做模型"的分界线。

## 阶段三：看见网络内部（约 3-5 天）

学了不可视化，等于没学。做三件事：

1. **决策边界演化**：画 two-moons 数据集上，第 0/5/20/100 epoch 的决策边界。
   你会看到网络怎么从一条直线"弯"成拟合月牙的曲线，**深度如何换来非线性**。
2. **可视化第一层权重**：把隐藏层权重画成二维小图（像卷积核那样），看它学到了什么方向的分界线。
   每个隐藏神经元其实就是在原空间画一条直线，多个神经元组合出复杂区域。
3. **看激活值分布**：训练中每隔若干 step 画一层 `Z1` 的直方图。
   BN 的作用、饱和问题会在这里现原形。

**验收标准**：能对着决策边界图说出"为什么 1 个隐藏神经元只能做出很粗糙的划分"（对应你实验 A 的 0.92）。

## 阶段四：把 MLP 放回它该在的位置（约 1-2 周）

MLP 本身不是终点，它是所有现代网络的"最后那个分类头"。理解它之后应该横向走：

1. **用 sklearn 对照**：`MLPClassifier` 两行就能解决 two-moons。
   然后**故意不用标准化**再跑一次，看它效果暴跌 → 亲手体会"特征工程 > 调参"。
2. **换个真实数据集**：MNIST（`torchvision.datasets`，CPU 上跑 MLP 几秒一轮）。
   从二维玩具数据到 784 维真实图片，你会遇到全新的问题：训练慢、要做归一化、要早停。
3. **然后才是 CNN / Transformer**：有了 MLP 的手写反向 + 可视化直觉，再学卷积会非常顺。
   推荐 **《动手学深度学习》(d2l.ai)** 中文版，有中文、有可运行代码、有免费 GPU 版。
