## 我们为什么需要CNN？

### 1. 参数的断崖式减少

给出一张 32×32×3 的彩色图像，展开后长度为：32×32×3=3072

假设第一个全连接层有 512 个神经元，那么参数量为多少？

而一个输入通道为 3、输出通道为 16、卷积核为 3×3 的卷积层，参数量又是多少？

请回答以下问题：

1. 两种方法的参数量分别是多少？

	全连接层：3072 * 512 + 512 = 1 573 376
	卷积层： 3 × 3 × 3 × 16 = 432

2. 为什么卷积层的参数量与图片宽高无关？

	卷积核是一组固定大小的可学习权重，无论图片是 32×32 还是 1024×1024，这套权重只有一份，所以参数只由「卷积核大小 × 输入通道 × 输出通道」决定，与空间尺寸无关

3. 参数过多会带来什么问题？

	- **过拟合**：模型记住训练样本（包括噪声）而不是学规律，训练集表现好、测试集差。
	- **数据需求大**：参数越多，需要的标注数据越多，否则难以训练充分。
	- **计算与显存开销**：内存、算力、训练时间、能耗都上升，推理变慢、部署成本高。
	- **优化困难**：梯度消失/爆炸、容易陷入局部最优，需要更精细的初始化和正则化。
	- **泛化与鲁棒性下降**：对输入的微小扰动更敏感，模型置信度校准往往变差。

### 2. 空间结构的关联性

请回答一个思考题：

- 将图片展平成一维向量后，原本相邻的像素是否仍然能被模型明确识别为“上下左右相邻”？

	不是"明确"识别，而是"隐含地编码在索引里"。 展平本身不丢信息（它是一个双射），相邻关系仍可从线性下标推出来；但网络结构里没有任何机制强制或保证它去利用这种关系——这要靠数据自己学出来。卷积层则把这种关系直接写进了结构。

### 3. 猫被移动以后也是一只猫

现在假设有两张图，第一张图有一只可爱的小茂密🐱在图片的左边，第二张图有一只一模一样的猫出现在了图片的右边。

- 如果模型已经学会在左上角检测猫耳朵，是否需要重新学习如何在右下角检测相同的猫耳朵？

	**如果是卷积网络：不需要重新学。** 卷积核在左上角学会了"猫耳朵"这个模式，它会被"平移"到右下角继续使用——同一组权重在整张图上滑动。右下角出现猫耳时，那个卷积核会**在特征图的右下角位置**被激活。学到的是"长什么样"，而不是"在哪个坐标"。
	
	**如果是展平后的全连接网络：基本需要重新学。** 左上角的猫耳对应输入向量的第 `0、1、32、33…` 几个下标，右下角的猫耳对应完全不同的下标。这两组输入连到隐藏层的是**彼此独立的权重**。网络必须为每个位置各学一套"耳朵检测器"，需要更多数据、更多参数，还容易过拟合。换句话说，FC 学到的是"下标 i、j、k 同时亮 = 有耳朵"，而不是"这个局部纹理是耳朵"。

- **什么是参数共享、平移等变性、平移不变性（？）**

	参数共享就是同一个权重（同一组卷积核）在不同空间位置上重复使用。
	
	平移等变性就是输入里的猫往右移 5 像素，输出的特征图里"猫耳朵激活"也跟着往右移 5 像素。内容不变，位置同步改变。
	
	平移不变性就是输入里的猫往右移 5 像素，输出一模一样
	
	分类网络就是多层卷积（等变）加全局池化（不变）

## 单通道图像中的卷积

### 1，2. 在不使用填充、步幅为 1 的情况下，请计算 (X) 与 (K) 的互相关结果。

1. 输出特征图的尺寸是多少？

	互相关就是"对应位置相乘再求和"，窗口在图上滑动。
	
	互相关结果为：$$
Y=
\begin{bmatrix}
 2 &  2 & -2\\
 3 &  3 & -3\\
 2 &  2 & -2
\end{bmatrix}
$$
	
	尺寸为3 * 3

2. 这个卷积核主要用于检测哪种方向的边缘？

	用于检测水平方向的亮度梯度，也就是竖直方向的边缘

3. 数学卷积和互相关有什么简单区别？

	数学卷积的结果就是互相关的结果旋转180度
	
	但是数学卷积满足交换律，结合律，而互相关不满足
	
	互相关更适合"用模板匹配图案"的语义


### 3. 填充与步幅

1. **什么是填充和步幅？**

	**填充（Padding）**：在做卷积前，在图像**四周补上若干圈像素**（通常是 0），用来控制输出尺寸、保住边界信息
	
	**步幅（Stride）**：卷积核每次滑动**跨几步**，用来控制输出尺寸、做下采样

2. **写出卷积输出尺寸的计算公式。**

	设输入高 H，核大小 K，每边填充 p，步幅 s：
	$$H_{out}=[\frac{H+2p-K}{s}]+1$$

### 4. 池化与感受野

1. 最大池化和平均池化分别会保留什么信息？

	最大池化保留每块的最大值，平均池化保留每块的平均值
	
	最大池化记的是"这块区域里最像某特征的地方有多强"；平均池化记的是"这块区域整体有多活跃"。
	
	最大池化保留了特征的"存在性"与强度，显著结构，尖峰，高频细节，局部平移鲁棒性，以及对少量位置扰动的容忍。平均池化保留了整体激活水平，平均强度，上下文和背景信息，抗噪性和数值稳定性

2. 什么是感受野？

	感受野就是输出特征图上的一个神经元，其数值取决于输入图像（或前一层）中的哪一片区域。它的大小就是一个神经元看得到的输入范围有多大。

## 彩色图像与多通道卷积

### 1. RGB的魔法

1. 写出卷积层权重和输出特征图的形状。

	卷积核权重是一个四维张量，形状为：
	$$(C_{out},C_{in},k_h,k_w)=(16,3,3,3)$$
	输出特征图的形状为：
	$$(N,C_{out},H_{out},W_{out})=(1,16,32,32)$$

2. 计算该卷积层的参数量。

	权重：$$3*3*3*16=432$$
	共432+16（bias）=448个参数

3. 使用示意图或文字说明：一个输出通道是如何由 R、G、B 三个输入通道共同得到的？

	一个输出通道 = 用 3 个独立的 3×3 卷积核分别作用在 R、G、B 上，得到 3 张中间结果，逐像素相加，再加一个偏置
	三个输入通道加权求和后变为一个输出通道

### 2. 麻雀虽小，五脏俱全——1×1 卷积

- 请计算输出尺寸和参数量，并解释：1×1 卷积没有观察相邻像素，为什么仍然有用？

	输出尺寸同样是$$3*32*32$$
	参数量只有$$1*1*3*16+16=64$$
	因为1 * 1卷积的只负责把各通道检测到的结果按学到的比例重新组合，负责通道降维，增加非线性而不扩大感受野
	至于跨像素的空间混合就交给更大的卷积来负责，有点小差异，各有各的美

## 完整CNN的结构

### 1. 庐山真面目

下面给出一个简单 CNN 的网络结构。该结构为示意代码，不要求直接运行：
```
输入：3 × 32 × 32

卷积层：Conv2d(3, 16, kernel_size=3, padding=1)
激活层：ReLU
池化层：MaxPool2d(kernel_size=2, stride=2)

卷积层：Conv2d(16, 32, kernel_size=3, padding=1)
激活层：ReLU
池化层：MaxPool2d(kernel_size=2, stride=2)

全局平均池化：GlobalAveragePooling
全连接层：Linear(32, 10)
```

1. 写出每一层的输出形状。

	第一层卷积层(16, 32, 32)
	第一层激活层(16, 32, 32)
	第一层池化层(16, 16, 16)
	第二层卷积层(32, 16, 16)
	第二层激活层(32, 16, 16)
	第二层池化层(32, 8, 8)
	全连接层(10)

2. 说明卷积层、激活函数、池化层和全连接层各自承担什么任务

	卷积层负责提取局部特征并做通道变换
	
	激活函数负责引入非线性，使网络能学习复杂函数
	
	池化层负责下采样、降维、增强一定平移鲁棒性
	
	全连接层负责把提取到的高层特征映射到最终输出类别或回归值

3. 为什么卷积层之间需要加入激活函数？

	卷积层本身是线性/仿射变换，只有加入非线性激活，多层网络才能真正学习复杂函数

4. 全局平均池化与直接使用Flatten展开有什么区别？

	全局平均池化保留通道信息，丢弃空间位置信息，且没有参数
	
	flatten保留通道和空间位置信息，但会让后续全连接层参数量变大

### 2. BatchNorm 与 Dropout

请查阅 BatchNorm 和 Dropout，并简单说明：

1. 它们各自有什么作用？

	BatchNorm对 CNN 中的 `(N, C, H, W)` 特征图，`BatchNorm2d` 通常对每个通道 `C` 统计当前 batch 在 `N,H,W` 上的均值和方差
	然后再做可学习的缩放和平移，让各层输入分布更稳定，允许使用更大学习率，加速收敛，一定程度上降低对初始化的敏感度，有轻微正则化效果，但它的主要定位不是 Dropout 那种正则化
	
	Dropout对输入张量的每个元素以概率 `p` 随机置零，并通常对保留元素做缩放
	防止神经元之间过度共适应，相当于训练很多子网络的集成，减少过拟合

2. 为什么它们在训练阶段和推理阶段的行为不同？

	因为训练阶段需要稳定优化、引入正则化并利用 batch 信息；推理阶段需要确定性、可复现、不依赖 batch 的稳定输出

## 现代卷积神经网络

现代卷积神经网络进行了很长一段时间的变革，从水下**AlexNet**的小试牛刀，到**ResNet**的现代文明，每一步都是智慧的结晶！

完成下面的表格：

| 网络          | 最有代表性的设计                                                                                                                               |
| ----------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| AlexNet     | ReLU 和 Dropout，使用了重叠最大池化和GPU并行训练                                                                                                       |
| VGG         | 通过反复堆叠极小的 3×3 卷积核来构建更深的网络                                                                                                              |
| NiN         | 1×1 卷积（mlpconv层）和全局平均池化（GAP）                                                                                                           |
| GoogLeNet   | Inception 模块，在同一层级上并行处理多尺度信息，以高效利用计算资源，1×1卷积降维                                                                                         |
| ResNet（重点！） | 残差连接，传统网络让堆叠层学习目标映射 `H(x)`；而ResNet让这些层学习残差映射 `F(x) = H(x) - x`，然后通过一条“捷径”将输入 `x` 直接加到输出上，得到 `F(x) + x`，使得梯度可以无阻碍地反向传播，从根本上解决了极深网络的训练难题 |
|             |                                                                                                                                        |
