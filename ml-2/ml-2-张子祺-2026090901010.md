## Part 1：解释下列概念

**1. 基础结构：**

- **隐藏层**

	指输入层和输出层之间的所有层。它本身不直接接触原始输入和最终结果，而是先对上一层的输出做一次线性变换，再经过激活函数做非线性变换，得到一组新的、更抽象的特征表示，再交给下一层。

	“隐藏”的含义是：训练数据里并不直接给出这些层应该输出什么，它们的表示是模型自己学出来的。隐藏层的层数和每层宽度决定了网络的表达能力，层数多（深）时，网络可以逐层组合出越来越复杂的特征：浅层学到边缘、纹理这类低级特征，深层学到形状、语义这类高级特征。

- **全连接层**

	全连接层中，每个输入神经元都和每个输出神经元相连，输出的每一维都是输入所有维的加权和，它对每个输入特征都单独给一个权重，所以能学习任意特征之间的全局组合关系，常放在特征提取部分之后做最后的分类/回归。

- **激活函数（Sigmoid、Tanh、ReLU、Leaky ReLU、Softmax）**

	作用：给网络引入非线性。如果没有激活函数，多层网络叠起来仍然是一层线性模型，深度就失去了意义。

	- **Sigmoid**：$\sigma(x)=\dfrac{1}{1+e^{-x}}$，值域 $(0,1)$，常用于二分类输出。缺点是：当 $|x|$ 较大时导数 $\sigma'(x)=\sigma(x)(1-\sigma(x))\to 0$，多层叠加会造成梯度消失；输出恒正、不是零均值。
	- **Tanh**：$\tanh(x)=\dfrac{e^{x}-e^{-x}}{e^{x}+e^{-x}}$，值域 $(-1,1)$，是零均值的，比 Sigmoid 收敛更快，但仍有梯度消失问题。
	- **ReLU**：$\mathrm{ReLU}(x)=\max(0,x)$，正区间导数恒为 1，所以正半轴不会梯度消失，且计算极快。缺点是负区间导数恒为 0，可能出现 Dead ReLU；输出也不是零均值。
	- **Leaky ReLU**：$f(x)=\max(\alpha x, x)$，$\alpha$ 一般取 0.01 等小常数。负区间保留一条很小的斜率，使梯度不至于完全断掉，从而缓解 Dead ReLU；$\alpha$ 也可作为可学习参数（PReLU）。
	- **Softmax**：$\mathrm{softmax}(z)_i=\dfrac{e^{z_i}}{\sum_j e^{z_j}}$，把一组实数变成和为 1 的概率分布，用于多分类的输出层，通常与交叉熵损失配合。实际实现时会先减去最大值以防指数溢出。

- **权重矩阵与偏置**

	$W$ 是权重矩阵，$W_{ij}$ 表示第 $j$ 个输入对第 $i$ 个输出的影响强度；$b$ 是偏置向量，它给每个输出一个可平移的常数。

	从几何上看，$W$ 决定超平面的方向（旋转、缩放），$b$ 决定超平面的位置（截距）——如果没有偏置，所有分界面都必须过原点，模型的自由度会大大降低，拟合能力受限。这两个量都是通过反向传播和梯度下降学习得到的参数

**2. 训练机制：**

- **前向传播**

	把输入数据沿网络从前往后计算一遍，得到预测值和损失值


- **反向传播**

	反向传播是链式法则在计算图上的高效实现，解决的是“信用分配”问题

	过程是先做一次前向传播并保存中间结果，然后从损失开始，沿着计算图的反方向逐层求导

- **损失函数（MSE、Binary Cross Entropy、Cross Entropy）**

	损失函数把模型预测与真实标签的差距量化为一个可优化的标量，它决定了优化的方向，也是反向传播的起点。

	- **MSE（均方误差）**：$\mathcal{L}=\dfrac{1}{n}\sum_{i=1}^{n}(\hat{y}_i-y_i)^2$，用于回归任务。它是凸函数、梯度  直观连续；缺点是对离群点非常敏感（误差被平方放大）。另外 MSE 配 Sigmoid 时，梯度中会出现 $\sigma'(z)$，两端饱和导致学习很慢，所以分类一般不用它。
	- **Binary Cross Entropy（二分类交叉熵）**：$\mathcal{L}=-\dfrac{1}{n}\sum_{i=1}^{n}\big[y_i\log \hat{y}_i+(1-y_i)\log(1-\hat{y}_i)\big]$，用于二分类/多标签任务，标签为 0/1，输出层用 Sigmoid。它与 Sigmoid 组合后梯度化简为 $\partial\mathcal{L}/\partial z=\hat{y}-y$，误差越大梯度越大，避免了 MSE 的饱和问题。
	- **Cross Entropy（多分类交叉熵）**：$\mathcal{L}=-\dfrac{1}{n}\sum_{i=1}^{n}\sum_{k=1}^{K}y_{ik}\log \hat{y}_{ik}$，用于互斥的多分类任务，标签是 one-hot，输出层用 Softmax。它衡量的是预测分布与真实分布之间的差异，同样与 Softmax 组合后梯度化为 $\hat{y}-y$，数值更稳定、收敛更快。

- **梯度下降与优化器（SGD、SGD+Momentum、Adam）**

	三种方法都是“沿着梯度反方向更新参数”，区别在于更新时用了多少历史信息、以及每个参数是否使用自适应步长。

	- **SGD（随机梯度下降）**：每次用小批量样本估计梯度并更新
		$$\theta \leftarrow \theta - \eta \nabla_\theta \mathcal{L}(\theta)$$
		它简单、内存小、泛化往往不错，但梯度噪声大，更新方向会在峡谷式损失面上来回震荡，收敛慢，对学习率非常敏感，也容易卡在鞍点或局部极小值。
	- **SGD + Momentum**：引入一个速度量累积历史梯度
		$$v \leftarrow \beta v + \nabla_\theta \mathcal{L},\qquad \theta \leftarrow \theta - \eta v$$
		$\beta$ 通常取 0.9。它让方向一致的维度越走越快（加速收敛），方向来回变化的维度相互抵消（抑制震荡），还能借助惯性冲出浅的局部极小和鞍点。
	- **Adam**：同时估计梯度的一阶矩（动量，方向）和二阶矩（梯度平方，尺度），并做偏差修正：
		$$m\leftarrow\beta_1 m+(1-\beta_1)g,\quad v\leftarrow\beta_2 v+(1-\beta_2)g^2,\quad
		\theta\leftarrow\theta-\eta\frac{\hat{m}}{\sqrt{\hat{v}}+\epsilon}$$
		其中 $\hat{m},\hat{v}$ 是偏差修正后的估计，默认 $\beta_1=0.9,\ \beta_2=0.999$。它为每个参数自适应地调整步长，收敛快、对学习率初值不敏感，是实践中的默认选择；不足是显存开销略大，某些任务上泛化略逊于精调的 SGD+Momentum，而且 L2 正则与自适应步长耦合，所以更推荐用解耦的 AdamW。

**3. 常见问题与对策：**

- **过拟合、欠拟合**

	- 过拟合：模型在训练集上误差很小，但在验证集上误差明显更大。常见原因有参数过多、训练轮数过多、数据太少或太单一。对策：增加数据或做数据增强、加 L1/L2 正则、用 Dropout、早停（early stopping）、减小模型或加约束、集成/多模型平均。
	- 欠拟合：训练集和验证集上的误差都偏大。常见原因有模型容量不足、特征不够、训练不充分、正则或 Dropout 过强、学习率不合适。对策：加宽加深网络、增加更有用的特征、训练更多轮、减弱正则化、调整学习率或换更好的优化器。
	- 实际做法是看训练和验证误差曲线：两者都高就是欠拟合；训练低验证高且差距随训练扩大就是过拟合。

- **梯度消失、梯度爆炸**

	- 梯度消失：当权重较小或激活函数进入饱和区（Sigmoid/Tanh 两端导数接近 0）时，连乘结果指数级衰减，浅层梯度趋近 0，参数几乎不更新，表现为靠近输入的层学不动、训练停滞。
	- 梯度爆炸：当权重较大时连乘结果指数级放大，梯度变成很大的值，损失出现 NaN/Inf，参数被一步更新到很远的坏区域。
	- 对策：使用 ReLU 类激活函数、合理的权重初始化（Xavier/He）、批归一化、残差连接（shortcut 提供梯度直通路径）、梯度裁剪（clip by norm/value，常用阈值 1~5）、LSTM/GRU 门控结构，以及更小的学习率。

- **暂退法（Dropout）**

	训练时以概率 $p$ 随机把某些神经元的输出置 0，其余神经元按 $1/(1-p)$ 放大，前向和反向都只经过保留下来的神经元；推理时不再丢弃，使用完整网络。

	作用：它阻止了神经元之间过于固定的共适应，迫使网络学到更鲁棒的特征，等价于对大量子网络做集成，因此是一种很强的正则化手段，能有效缓解过拟合。注意点：训练和推理必须切换模式（`model.train()` / `model.eval()`）；丢弃率一般取 0.2~0.5，太大反而欠拟合；常加在全连接层之后，卷积层用得较少；一般不与 BN 同时堆在同一位置（BN 已有轻微正则效果）。

- **权重衰减（L1 / L2 正则化）**

	在损失里加入对权重的惩罚项，限制权重的幅度，从而降低模型复杂度：

	- **L2 正则（权重衰减）**：$\mathcal{L}' = \mathcal{L} + \dfrac{\lambda}{2}\|W\|_2^2$，梯度中多出 $\lambda W$，更新时权重每步都被按比例缩小（$\theta\leftarrow(1-\eta\lambda)\theta-\eta\nabla\mathcal{L}$），所以叫“权重衰减”。它让权重分布更平滑、更小，降低对个别特征的依赖，是最常用的正则化手段。
	- **L1 正则**：$\mathcal{L}' = \mathcal{L} + \lambda\|W\|_1$，其梯度为常数 $\lambda\,\mathrm{sign}(W)$，会把不重要的权重直接压到 0，产生稀疏解，可用于特征选择。
	- 注意点：$\lambda$ 越大正则越强，过大会导致欠拟合；在 Adam 中应使用 AdamW，把权重衰减与自适应梯度解耦，否则正则效果会被自适应步长削弱。

- **批归一化（Batch Normalization）**

	对一个 mini-batch，在每一层的线性输出之后、激活函数之前，按特征维度做标准化，再做一次可学习的仿射变换：

	$$\hat{z}=\frac{z-\mu_B}{\sqrt{\sigma_B^2+\epsilon}},\qquad y=\gamma\hat{z}+\beta$$

	其中 $\mu_B,\sigma_B$ 是该 batch 内的均值和方差，$\gamma,\beta$ 是可学习参数（保证网络仍能表达原来的分布）。训练时用当前 batch 的统计量并维护滑动平均；推理时用训练阶段累积的全局统计量。

	作用：让每层输入的分布保持稳定，缓解内部协变量偏移，从而允许更大的学习率、加快收敛、降低对初始化的敏感性，并带有轻微的正则效果。注意点：第 1 维通常不归一化（不处理 batch 维）；batch 很小时统计量不稳、效果变差，此时可用 LayerNorm/GroupNorm；训练与推理必须使用各自的统计量。

- **权重初始化（Xavier、He 初始化）**

	初始化的目标：让前向传播中每层输出的方差、以及反向传播中梯度的方差在各层间大致保持稳定，避免信号逐层衰减或放大。

	- 不能全部初始化为 0：所有神经元的输出和梯度完全相同，对称性无法被打破，网络等价于只有一个神经元。
	- 不能方差太大或太小：太大导致梯度爆炸/激活饱和，太小导致信号和梯度逐层衰减（梯度消失）。
	- **Xavier（Glorot）初始化**：适用于 Sigmoid/Tanh 等对称、线性的激活，取
		$$W\sim\mathcal{N}\Big(0,\ \frac{2}{n_{in}+n_{out}}\Big)$$
		它同时考虑了前向和反向的方差（$n_{in}$ 与 $n_{out}$）。
	- **He（Kaiming）初始化**：适用于 ReLU 及其变体。因为 ReLU 会把负半轴置 0，相当于方差减半，所以需要把方差放大一倍：
		$$W\sim\mathcal{N}\Big(0,\ \frac{2}{n_{in}}\Big)$$
	- 实践中还有一个重要细节：偏置通常初始化为 0（ReLU 可设为很小的正数），而 BN 层前的权重是否需要按增益缩放取决于其后是否有激活。

- **Dead ReLU 问题**

	指某个 ReLU 神经元对所有（或绝大多数）输入都落在负半轴，输出恒为 0；由于 ReLU 在负区间导数恒为 0，反向传播时传不到它这里，它的权重和偏置再也得不到更新，这个神经元就“死掉”了，永久失效，网络的等效容量随之下降。若死亡神经元很多，模型表达能力明显受损。

	产生原因：学习率过大导致一次更新把权重推到使 $z<0$ 的区域；初始化方差过大或偏置为较大的负数，使神经元一开始就处于负区；训练数据分布导致该神经元长期得不到正响应。

	对策：改用 Leaky ReLU / PReLU / ELU / GELU 等在负区间保留梯度的激活函数；使用 He 初始化、批归一化；适当降低学习率或使用学习率预热；若死亡比例过高，也可考虑重新初始化该层。

	需要区分它与“稀疏激活”：ReLU 输出本来就有约一半为 0，这是正常的稀疏性、有利于计算和泛化；只有当神经元对所有输入都恒为 0、且梯度长期为 0 时才是问题。

## Part 2：回答问题

**1. XOR 问题与 MLP 的意义**

- 为什么单层感知机（线性模型）无法解决 XOR 异或问题？请从几何角度分析。

	单层感知机的决策边界是
$$
w_1x_1+w_2x_2+b=0
$$
	在二维平面上，这是一条**直线**，把平面分成两半
	XOR的四个样本分别在（0，0）（0，1）（1，0）（1，1）
	如果单层感知机能解决 XOR，就必须找到一条直线，使得两个正类点在同一侧，两个负类点在另一侧。但从几何上看，这是做不到的

- MLP 是如何解决 XOR 问题的？最少需要几个隐藏层、几个隐藏神经元？

	MLP 解决 XOR 最少需要 1 个隐藏层、2 个隐藏神经元
	使用阶跃激活函数：
$$
step(z)=
\begin{cases}
1,z>=0\\
0,z<0
\end{cases}

$$
	隐藏层：
$$h_1=step(x_1+x_2-0.5)
\\h_2=step(x_1+x_2-1.5)$$
	输出层：
$$y=step(h_1-h_2-0.5)$$
	输出就是XOR

**3. 激活函数对比：ReLU vs Sigmoid vs Tanh**

- (1) 从梯度特性角度对比三者的优缺点。

	Sigmoid：梯度消失严重，导数最大值只有 0.25，当输入进入饱和区（∣x∣ 较大）时，σ′(x)→0。
	
	ReLU：正区间梯度恒为 1，不会像 Sigmoid/Tanh 那样在正饱和区梯度消失。
	但是负区间梯度为 0，一旦神经元进入负区间且不再更新，可能永久失活，即 Dead ReLU。
	
	Tanh：导数最大值是 1，比 Sigmoid 的 0.25 大，梯度消失相对轻一些。但是仍然存在饱和区，当 ∣x∣较大时，tanh⁡′(x)→0，深层网络仍会梯度消失。

- (2) 什么是 Dead ReLU 问题？它是如何产生的？如何缓解？

	Dead ReLU 指某个 ReLU 神经元对几乎所有输入都输出 0
	
	产生的原因可能是学习率过大，偏置初始化为较大负值，某些输入特征总是使加权和小于 0，或是训练过程中偏置不断变小，使神经元倾向于输出 0
	
	缓解办法：使用Leaky ReLU，负区间给一个小的非零斜率，避免梯度完全为 0，使用合适的初始化如 He 初始化，降低学习率，使用Adam等自适应优化器，将偏置初始化为 0 或小的正值，进行梯度裁剪等

- (3) Sigmoid 的计算涉及指数运算，前向传播和反向传播中通常用什么方法简化算？

	前向传播中：
	
	使用tanh实现，间接计算sigmoid
	
	预先计算一定范围内 Sigmoid 的值并存储，推理时根据输入查表
	
	分段线性/分段多项式近似：将输入区间分段，每段用线性函数或低阶多项式逼近
	
	截断饱和区，可以设置阈值直接返回 0 或 1，避免指数计算
	
	用位操作或查表近似 ex，例如经典 Fast Sigmoid 近似，但精度较低，通常只用于特定场景
	
	反向传播中：
	
	Sigmoid 反向传播通常不需要重新计算指数，因为前向传播时已经计算并保存了输出，反向传播时直接使用

**4. 暂退法（Dropout）如何防止过拟合？**

- 请从集成学习（Ensemble）和特征共适应的角度解释 Dropout 的工作原理。

	从集成学习的角度来讲：这等价于从完整网络中**随机抽取一个子网络**。完整网络包含 n 个神经元，那么理论上可以产生 $n^2$ 种不同的子网络。集成平均通常能降低方差、减少过拟合。Dropout 用极低的计算和存储成本，近似实现了指数级多个子网络的集成效果
	
	从特征共适应的角度来讲：特征共适应就是神经元过度依赖其他特定神经元的存在，导致一旦某个特征在测试时缺失或噪声较大，整个组合就会失效。Dropout 随机丢弃神经元，使得任何神经元都不能假定其他特定神经元一定存在。因此，每个神经元都被迫学习更独立、更鲁棒的特征，而不是依赖脆弱的固定组合

- 为什么训练时使用 Dropout，测试时却需要关闭它？

	因为训练时使用dropout是为了正则化，防止过拟合。而测试时要获得稳定的预测希望使用所有神经元，而不是只用一个随机子网络
