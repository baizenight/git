# 做题心得

## AI工具的使用

- 在完成前端题目的过程中，我大量使用了AI工具来帮助我快速完成，发现AI在前端方面真的是降维打击，尤其是在编写css和JavaScript的时候，怪不得说前端已死。我做题的过程是这样的：先读题，看文档，询问网页版AI题目大致需要用到哪方面知识，然后先手搓一坨跑不起来的代码，丢给AI纠错并逐行解释，最后欣然采纳AI的方案。

## 对于node.js

- node.js 和浏览器上的JavaScript 语法没有区别，本质上只是面向的对象不一样，node.js 关注服务器和系统能力，而JavaScript 关注页面和用户界面，所以提供的功能，模块和运行方式不同。
- localhost: 3000 中 localhost 是主机名，3000是端口
- request 是客户端向服务端的请求，包含请求方式，请求地址，请求头，请求体；respons 是服务端向客户端的响应，包含状态码，响应头，响应体
- 返回对象前需要使用 JSON.stringify ，因为不能直接传输 JavaScript 对象，需要先序列化成JSON字符串，才能写进响应体发给客户端
- 为什么访问不同路径会得到不同数据？因为server.js 里面有一个路由模块，根据请求的地址不同，返回的数据就不同
